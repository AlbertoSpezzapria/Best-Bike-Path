This section specifies the APIs provided and required by the major components identified in the Component View. The interfaces are categorized into \textbf{Hardware Abstraction Interfaces} (internal to the Hybrid Client) and \textbf{Network Interfaces} (between Client and Cloud).

\subsection{Hardware Abstraction Interfaces}
These interfaces are exposed by the \textbf{Native Bridge (Capacitor)} and consumed by the \textbf{Sensor Controller} within the web runtime.

\paragraph{Interface: IGeolocationProvider}
\begin{itemize}
    \item \textbf{Description:} Provides access to the device's GPS hardware.
    \item \textbf{Provided By:} Native Bridge (\texttt{@capacitor/geolocation}).
\end{itemize}

\subsection{Cloud Network Interfaces (BaaS API)}
The communication contract between the \textbf{Hybrid Client} and \textbf{Supabase} uses RESTful endpoints for CRUD operations and RPC for geospatial logic.

\paragraph{Interface: IAuthService}
\begin{itemize}
    \item \textbf{Description:} Manages user sessions via Supabase GoTrue.
    \item \textbf{Protocol:} HTTPS / REST
\end{itemize}

\begin{table}[H]
\centering
\renewcommand{\arraystretch}{1.4}
\resizebox{\textwidth}{!}{%
    \begin{tabular}{|p{0.25\textwidth}|p{0.25\textwidth}|p{0.20\textwidth}|p{0.20\textwidth}|}
    \hline
    \textbf{Endpoint / Method} & \textbf{Input Payload} & \textbf{Response} & \textbf{Description} \\
    \hline
    \texttt{POST /auth/v1/signup} & \texttt{\{ email, password \}} & \texttt{\{ user, session \}} & Registers a new user and creates a profile in the public schema. \\
    \hline
    \texttt{POST /auth/v1/token} & \texttt{\{ email, password \}} & \texttt{\{ access\_token \}} & Authenticates a user (Login). \\
    \hline
    \end{tabular}%
}
\caption{IAuthService Interface}
\end{table}

\paragraph{Interface: ISpatialDataStore}
\begin{itemize}
    \item \textbf{Description:} Provides CRUD access to geospatial entities. Operations are strictly governed by \textbf{Row Level Security (RLS)}.
    \item \textbf{Protocol:} HTTPS / REST (PostgREST)
\end{itemize}

\begin{table}[H]
\centering
\renewcommand{\arraystretch}{1.4}
\resizebox{\textwidth}{!}{%
    \begin{tabular}{|p{0.25\textwidth}|p{0.25\textwidth}|p{0.20\textwidth}|p{0.20\textwidth}|}
    \hline
    \textbf{Endpoint / Method} & \textbf{Input Payload} & \textbf{Response} & \textbf{Description} \\
    \hline
    \texttt{GET /rest/v1/paths} & \texttt{select=*, is\_public=eq.true} & \texttt{JSON Array} & Retrieves public paths. \\
    \hline
    \texttt{POST /rest/v1/activities} & \texttt{\{ path\_id, geom, hazards \}} & \texttt{201 Created} & Uploads an activity. Triggers \texttt{update\_path\_consensus} asynchronously. \\
    \hline
    \end{tabular}%
}
\caption{ISpatialDataStore Interface}
\end{table}

    \item \textbf{Protocol:} HTTPS / RPC
