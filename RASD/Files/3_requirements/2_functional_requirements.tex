\subsubsection{Sign Up \& Login}
The platform allows users to create an account, access the system, and recover credentials. Guest access is limited.

\begin{itemize}
    \req The platform allows users to create an account by providing the required personal information.
    \req The platform allows registered users to log in and access the system.
    \req The platform allows registered users to recover the access credentials.
    \req The platform allows guest users (non-registered users) to access only the path search functionality of the system.
\end{itemize}

\subsubsection{Activity recording}
The system enables users to track their cycling activities and collect sensor data.

\begin{itemize}
    \req The system shall allow registered users to start recording a new cycling activity.
    \req The system shall allow users to select an existing path from the path public repository to follow during the activity (not mandatory).
    \req The system shall collect raw data from the mobile device’s sensors (GPS, accelerometer, gyroscope) during the recording of an activity.
    \req The system shall analyze the user’s speed derived from GPS data to verify if the user is effectively cycling.
    \req The system shall analyze accelerometer and gyroscope data to detect potential obstacles or road surface anomalies.
    \req The system shall calculate real-time statistics during the recording, including total distance covered and average speed.
    \req The system shall allow the user to pause and resume the recording of an activity.
\end{itemize}

\subsubsection{Path creation}
The system handles the creation of new paths through two modes: automatic detection from an activity or manual creation via map.

\paragraph{Automatic Creation}
\begin{itemize}
    \req Upon stopping an activity, the system shall display the list of automatically detected obstacles.
    \req The system shall require the user to validate the detected obstacles before proceeding.
    \req After validation, the system shall analyze the recorded GPS trace to identify if it matches an existing path in the database.
    
    % Scenario: Match found
    \req If the recorded trace matches an existing public path, the system shall automatically associate the activity with that path entity.
    \req The system shall use the validated data to update the status and information of the existing public path.
    \req The system shall add the identified path to the ``My paths'' section if not already present.
    
    % Scenario: No match found
    \req If the recorded trace doesn't match any existing public path, the system shall allow users to generate a new path entity starting from the GPS trace of a recorded activity.
    \req The system shall allow the user to associate a name to the recorded path and store it in the ``My paths'' section.
\end{itemize}

\paragraph{Manual Creation}
\begin{itemize}
    \req The system shall allow the user to create a new path manually by selecting a sequence of streets from a map.
    \req The system shall require the user to manually input the status of the streets composing the path and mark the position and type of obstacles along it.
    \req The system shall allow the user to assign a name to the manually created path and store it in the ``My Paths'' section.
\end{itemize}

\subsubsection{Path search from origin to destination}
\begin{itemize}
    \req The platform allows users to search for cycling paths based on a starting point and an ending point.
    \req The platform allows users to filter the search results based on the path parameters.
\end{itemize}

\subsubsection{Path ranking}
\begin{itemize}
    \req The platform is able to rank the available paths based on the path data, including the condition of each segment, the freshness of the information, and the effectiveness of the path in connecting the selected points.
\end{itemize}

\subsubsection{Entering path condition information}
\begin{itemize}
    \req The platform is able to detect when a registered user follows a path that is already available to the public and associate the activity with that path.
    \req The platform allows registered users to update the condition information of a path, even without performing an activity on that path.
\end{itemize}

\subsubsection{Path management and publication}
\begin{itemize}
    \req The system shall allow users to edit the information (name, street status, obstacles) of any path they have created.
    \req The system shall allow users to publish a stored path, making it available to the community.
\end{itemize}
