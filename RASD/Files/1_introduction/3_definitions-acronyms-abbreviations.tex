\subsection{Definitions}
\begin{itemize}
    \item \textbf{Activity}: A recorded session of a cycling trip that includes temporal data, performance metrics, and environmental conditions.
    \item \textbf{Automatic Mode}: A feature that enables the system to autonomously record the route and detect obstacles using the device's sensors (GPS, accelerometer, gyroscope).
    \item \textbf{Guest User}: An unauthenticated user who can access the system with limited privileges, specifically restricted to searching and viewing public paths.
    \item \textbf{Manual Mode}: A mode that allows users to create a path by manually selecting streets and defining conditions on the map, without physical recording.
    \item \textbf{Merging}: The system process that aggregates feedback and data from multiple users to update the status and reliability of a public path.
    \item \textbf{Path}: The core entity representing a bike route, defined by a sequence of geographic coordinates and metadata. It can be private or public.
    \item \textbf{Registered User}: An authenticated user with a personal profile who can record activities, create paths, and contribute feedback to the community.
\end{itemize}
