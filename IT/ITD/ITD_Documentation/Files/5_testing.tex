\section{Testing}

The implementation has undergone a rigorous testing phase focusing on the geospatial algorithms, data integrity constraints, user permission logic (Row Level Security), and privacy-aware workflows.  
The following subsections describe the main validation scenarios designed to ensure correctness, usability, and protection of community data.
